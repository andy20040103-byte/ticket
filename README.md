# 🎵 管樂團團員專屬售票系統（大東文化藝術中心演藝廳）

專為管樂團公演設計的現代化視覺選位系統。採用**溫潤象牙白底搭配大地土色調**的高雅設計，全館 1:1 電影院式畫布劃位、團員專屬優惠自動試算、Google 試算表即時後台串接、防撞位自動撤單保護與團員自主查詢/取消訂位功能。

## 🌟 核心特色功能

1. **大東演藝廳 1:1 全館同畫布直觀瀏覽**
   - **1 樓觀眾席 (共 574 席，含工作席)**：
     - 1~4 排不開放（不設席次）。
     - 5~7 排最佳區：$1000 元（玫瑰洋紅，含節目冊）。
     - 8~14 排主力區：$500 元（焦糖琥珀，含節目冊）/ 兩側外緣 $300 元（沈穩暖藍）。
     - 15~18 排全面：$300 元（沈穩暖藍）。
     - **17~18 排中央區（共 24 席）**：忠實依據場地標記為**「攝影席（不開放預訂）」**，避免誤選。
   - **2 樓觀眾席 (共 173 席)**：
     - 直接整合於一樓下方同一畫布，無需分頁切換。
     - 2~6 排全區草綠色 $100 元。
   - **3 樓觀眾席**：標記為本場次不開放。

2. **團員專屬優惠自動試算引擎**
   - 🎁 **優惠 1**：每位團員享 **2 張免費** 300 元座位（系統自動折抵 $0 元，省 $600）。
   - 🎟️ **優惠 2**：其餘座位一律 **7 折**（100 元席除外，維持原價）。
   - 📖 **優惠 3**：1000 元及 500 元座位，每席皆**隨票贈送精美節目冊乙本**（系統自動統計總本數）。

3. **個資安全與自主訂位管理**
   - 訂票要求必填**「電子信箱 (Email)」**作為核身憑證。
   - 團員可於右上角點擊**「🔍 查詢 / 取消訂單」**輸入 Email，隨時查閱自己登記的座席明細與金額。
   - 支援**「取消此筆訂單」**功能：團員訂錯可自行退訂，系統即刻釋放該席位給其他人選購。
   - 前台完全**不公開 Google 試算表連結與後台設定**，保障全體團員隱私！

4. **即時防撞位保護機制（自動撤單提醒）**
   - 送出訂單時，系統即刻與後端比對座位狀態。
   - 若填表期間該席位剛好被其他人搶先一步預訂，系統將**自動取消此筆訂單**，並跳出**「⚠️ 席次已被搶先登記」**專屬警示彈窗，明確列出衝突座位，引導重新挑選。

5. **象牙白與大地土色調典雅視覺**
   - 揮別刺眼暗黑高對比，採用象牙白底（Ivory）、陶土棕（Terracotta）、暖焦糖色調，閱讀舒適且具藝術氛圍。
   - 初始狀態**完全乾淨空白，無任何預設售出假席次**。

## 📁 檔案結構說明

```text

└── 大東位置票價圖.jpg            # 原始演藝廳座位票價對照圖
```

## 🚀 如何發布到 GitHub Pages

1. 在 GitHub 建立一個公開儲存庫（例如：`windband-tickets`）。
2. 將本專案資料夾內的所有檔案推送到該儲存庫 `main` 分支。
3. 進入該儲存庫的 **Settings** -> **Pages**。
4. 在 **Branch** 選擇 **`main`**，資料夾選擇 **`/ (root)`**，點擊 **Save**。
5. 1 分鐘後即可開啟網址開始使用！
